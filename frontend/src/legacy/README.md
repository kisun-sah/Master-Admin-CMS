# Legacy Dormant Code Archive

These files (`main.jsx` and `App.jsx`) were part of the initial monolithic frontend prototype.

The production architecture has decoupled the application into two isolated applications:
1. **Public Website:** `index.html` -> `/src/public/main.jsx`
2. **Master Admin CMS:** `admin.html` -> `/src/admin/main.jsx`

These files are preserved in this archive directory for historical reference only and are not bundled into production.
